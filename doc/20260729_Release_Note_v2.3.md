# 流痕 (Flow Track) v2.3 - 版本发布说明

**发布日期**: 2026年7月29日  
**版本代号**: v2.3 (显示桌面增强与UI状态修复)

---

## 🌟 核心新特性与增强

### 1. 🖥️ 全屏模式兼容：自动发送 ESC 退出全屏
- **功能背景**: 过去在遇到视频播放器、游戏或全屏浏览器等窗口时，Windows 系统的 `Win+D` 组合键可能无法顺利最小化所有窗口。
- **全新机制**: 在执行“显示桌面”指令前，系统会自动模拟一次 `ESC` 键触发，并休眠 300 毫秒等待界面退出全屏状态，极大增强了桌面操作的成功率与可靠性。

### 2. 🎨 桌面图标状态视觉矫正
- **修复问题**: 修复了之前勾选“显示桌面”时旁边的桌面图标反向灰掉的逻辑缺陷。
- **全新表现**: 
  - **启用时**: 桌面图标亮起绿光，直观指示桌面模式处于激活状态。
  - **未启用时**: 桌面图标呈灰色。
  - **运行时**: 全局安全锁定下，所有图标统一置灰防误触。

---

## 🔧 技术改进细节

1. **单例互斥锁升级**: 核心互斥锁名称升阶至 `Local\\FlowTrack_Instance_Mutex_9D2A3B4C-v2.3`，保障新旧版本的独立进程管理。
2. **多语言日志全覆盖**: 日志面板新增中英文对应执行提示：`正在发送 ESC 以退出全屏模式...` / `Sending ESC to exit fullscreen mode...`。
